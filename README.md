# GR SSO

SSO-сервер, реализующий централизованную аутентификацию
и авторизацию приложений через OAuth 2.0 / OpenID Connect.

## Возможности

- OAuth 2.0 / OpenID Connect
- Authorization Server
- OAuth2 Client
- Централизованное управление пользователями
- Управление OAuth2-клиентами
- Управление сессиями авторизации
- Хранение данных в PostgreSQL
- Redis для временных данных
- Миграции базы данных через Flyway
- Отправка email
- Определение User-Agent & GeoIP
- WebDAV через Sardine
- Модульная архитектура на Spring Modulith
- Модульное и интеграционное тестирование 

## Архитектура

Проект организован как модульное приложение на базе Spring Modulith:

| Модуль | Назначение                         |
|---|------------------------------------|
| `authentication`    | Аутентификация пользователей       |
| `authorization_sso` | OAuth2 / OIDC Authorization Server |
| `oauth_client`      | Управление OAuth2-клиентами        |
| `oauth_session`     | Управление OAuth2-сессиями         |
| `user`              | Пользователи и связанные данные    |
| `email`             | Отправка email сообщений           |
| `attachment`        | Работа с файлами/вложениями        |
| `system`            | Системные настройки                |
| `infrastructure`    | Инфраструктурные интеграции        |
| `common`            | Общие компоненты                   |
